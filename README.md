## About

CafeCounter is a modern Point of Sale (POS) application designed for coffee shops and cafés.

The project is being built from scratch with a focus on:

- Clean Architecture
- Scalability
- Modern UI/UX
- High Performance
- Production-ready codebase

---

## Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Zustand

### Backend

- Go
- Fiber
- GORM

### Infrastructure

- Supabase (PostgreSQL & Storage)
- Resend
